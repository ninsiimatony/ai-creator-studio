# Night Tales Uganda — Photo prompts (v1)

## HOW TO USE
1. In ChatGPT, start a new chat. Paste the **STYLE LINE** first (once).
2. Then paste ONE prompt at a time. Ask for **wide 16:9** pictures.
3. Make 1–2 pictures per prompt. Send them to Claude (as PDFs or photos, like before).
4. Claude names each picture and puts it in the robot's folder. The robot picks the right one for each part of the story.

## STYLE LINE (paste first)
Make every picture a photorealistic cinematic horror film still, shot at night in rural Uganda, wide 16:9, dark moody lighting, deep shadows, slight film grain, ultra detailed. NO text, NO words, NO logos, NO watermark, NO pumpkins, NO Western-style houses. Ugandan setting only: mud-brick houses with tin or thatch roofs, banana plantations, red dirt paths, kerosene lanterns, boda boda motorbikes.
