# AI Creator Studio

Build a polished, responsive web app named Tony AI YouTube Studio. This is a new standalone project, not an edit to any existing project. Purpose: help operate a YouTube channel about AI technology, AI tools, robotics, and the future for a worldwide audience. Content style: faceless documentary/explainer videos with AI narration. Workflow: generate ideas and scripts, prepare video production briefs, review drafts, and require Tony's explicit approval before anything is published. Do NOT connect external accounts, request credentials, deploy, spend money, or publish anything. Build the first-stage dashboard UI with realistic demo data and clearly label all integrations as Not connected / Demo until genuinely configured. Include: overview dashboard; content calendar; idea research queue; script editor with hook/outline/CTA fields; video production pipeline (script, voiceover, visuals, captions, thumbnail, quality check); approval queue; YouTube channel connection screen explaining secure Google OAuth (never ask for password); analytics page with views, watch time, retention, CTR placeholders; settings for target audience worldwide, preferred format faceless documentary, publishing approval required, timezone Asia/Muscat, and daily budget cap fields. Use a premium dark navy/charcoal interface with teal accents, clean typography, mobile-first responsive layout, accessible controls, and simple navigation. Make the UI honest: demo data only, no fake successful uploads or analytics. Add clear next-step integration placeholders for a future cloud automation backend and YouTube Data API. Start with a useful working frontend and local/demo state; do not imply unattended automation is already active.
